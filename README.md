
### Common
프로젝트에 종속되지 않은 공용 스크립트

### Gameplay
FluffyWitch의 게임 플레이 스크립트

- **Combat** : 전투 관련 스크립트 (데미지 계산 로직 등)
- **Entities** : 캐릭터, 투사체, 아이템 등의 Entity 스크립트들과, 스탯·상태효과와 같은 Entity와 관련된 스크립트
- **Stage** : 플레이어·적 스폰 등 스테이지 관련 스크립트
- **FXs** : VFX / SFX 스크립트
- **ScriptableAction** : ScriptableObject를 통해 액션을 발동시킬 수 있는 기능
- **Weapons** : 무기 스크립트
- **UI**
- **Utils**

### Infrastructure
게임 플레이에서 필요로 하는 서비스를 제공하는 스크립트
(풀링, 에셋 로딩 등)
