# 스탯 시스템

캐릭터 능력치의 계산 코어입니다. 장비 · 패시브 · 영구강화 · 난이도 · 상태이상 등 게임의 모든 능력치 보정이 하나의 모디파이어 모델(`StatModifier`)로 통일되어 있고, 출처(Source) 단위로 정확히 되돌릴 수 있습니다.

> 본 폴더는 실제 프로젝트에서 발췌한 소스로, 단독 컴파일 대상이 아닙니다.

## 읽는 순서

| 순서 | 파일 | 내용 |
|---|---|---|
| 1 | `StatType.cs` | 스탯 종류 |
| 2 | `StatModifierType.cs` / `StatModifier.cs` | 모디파이어 모델 — 3종 합성 방식 + 출처(Source) |
| 3 | `Stat.cs` | **핵심** — 합성 공식, dirty 캐싱, 변경 통지 |
| 4 | `StatDefinition.cs` | 스탯별 min/max 정의 (도메인 공용 에셋에서 관리) |

## 핵심 포인트 위치

- **합성 공식과 캐싱** — `Stat.CalculateFinalValue()` / `Stat.Value`
  `(base + ΣFlat) × (1 + ΣPercentAdd) × Π(1 + PercentMultiply)` 후 min/max 클램프.
  dirty 플래그로 조회 시점에만 재계산하되, `ValueChanged` 구독자가 있으면 변경 즉시 재계산해 통지합니다.
- **출처 기반 일괄 제거** — `Stat.RemoveAllModifiersFromSource()`
  모디파이어가 출처 객체를 기억하므로, 장비 해제 시 그 장비가 준 보정만 정확히 걷어냅니다.
- **정수 스탯 내림 정책** — `Stat.CalculateFinalValue()` 마지막 줄
  정수 차원 스탯(HP·공격력 등)은 모든 모디파이어 합산 후 최종값에서 **한 번만** 내림합니다 —
  모디파이어별로 미리 내리면 오차가 누적되기 때문입니다.
- **풀링 대응 리셋** — `Stat.Reset()`
  캐릭터가 오브젝트 풀로 반환될 때 호출되어, 스폰 중 부여된 모디파이어가 다음 스폰으로 새지 않습니다.
- **직렬화 안정성** — `StatType.cs`
  enum 값을 도메인별 번호 구간(100 / 1000 / 2000)으로 명시해, 항목 추가·정렬이
  기존 에셋의 직렬화 값을 깨뜨리지 않습니다.
